# Remodel Quote Tools

Good / better / best quote generators for a remodeling business. Static HTML, no build step.

- `classic/` – internal quote tool with editable price book (saved in the browser)
- `blueprint/` – customer-facing step-by-step estimate
- `mix-match/` – pick a tier per line item
- `budget-fit/` – budget slider that builds the best package that fits
- `data.js` – shared sample price book used by the last three

All prices are placeholders. Replace them in `data.js` (and in the Classic tool's price book).

## Hosting on GitHub Pages
Settings → Pages → Deploy from a branch → `main` / root.
